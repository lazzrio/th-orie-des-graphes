Chapitre 3 — Problèmes de coloration (partie 1)

Objectifs : modéliser un problème de contraintes par un problème de coloration ; construire et évaluer une coloration propre ; concevoir et comparer différentes stratégies de coloration.

I. Définitions

1. Sommets et arêtes — degré d'un sommet

Définitions
  • Deux sommets sont adjacents s'il existe au moins une arête entre eux.
  • Un sommet est pendant s'il n'est adjacent qu'à un seul autre sommet.
  • Un sommet est isolé s'il n'est adjacent à aucun autre sommet.
  • Deux arêtes sont adjacentes si elles ont au moins une extrémité en commun.
  • Une arête est incidente à un sommet s si s est l'une de ses extrémités.
  • Le degré d'un sommet s, noté deg(s), est le nombre d'arêtes incidentes à s. Dans un graphe simple d'ordre n, c'est aussi le nombre de sommets adjacents à s et deg(s) ≤ n−1.
ss1s2s3s4s5s6
deg(s)122410

Adj(s2) = {s3, s4}. {s2,s3} et {s3,s4} sont adjacentes. {s1,s4} est incidente à s1 et à s4.

Complément (lemme des poignées de main)Dans un graphe non orienté de taille m : Σ deg(s) = 2m (chaque arête compte deux fois). Ici 1+2+2+4+1+0 = 10 = 2×5. Conséquence : le nombre de sommets de degré impair est toujours pair.

2. Sous-graphes — graphes partiels

DéfinitionsSoit G = (S, A) un graphe.
  • Un sous-graphe de G est un graphe G′ = (S′, A′) avec S′ ⊆ S et A′ = les arêtes de A dont les deux extrémités sont dans S′.
  • Un graphe partiel de G est un graphe G′ = (S, A′) avec A′ ⊆ A : mêmes sommets, certaines arêtes seulement.

3. Graphe complet

DéfinitionUn graphe simple est complet si et seulement si ses sommets sont deux à deux adjacents : pour deux sommets distincts x et y, il existe une arête reliant x à y. On note Kn le graphe complet d'ordre n.
À savoirDans Kn : tous les sommets ont pour degré n−1 et il y a n(n−1)/2 arêtes (K2 : 1, K3 : 3, K4 : 6, K5 : 10). Justification : Σ deg = n(n−1) = 2m.

II. Problèmes de coloration — domaines d'applications

1. Définitions

Définitions
  • Étant donné un graphe simple non orienté G = (S, A), une coloration propre est une fonction f qui attribue une couleur à chaque sommet de sorte que deux sommets adjacents n'aient jamais la même couleur : ∀ {x,y} ∈ A, f(x) ≠ f(y).
  • G est k-colorable s'il existe une coloration propre avec k couleurs.
  • Le nombre chromatique χ(G) est le plus petit entier k pour lequel G est k-colorable.

2. Problématiques et domaines d'applications

  • Problèmes de production (trouver une solution) : comment trouver une coloration propre de G ? Quel est le nombre chromatique de G ?
  • Problèmes de décision (une solution existe-t-elle ?) : peut-on trouver une coloration propre minimale ? Étant donné k < n, G est-il k-colorable ?

De nombreuses problématiques d'attribution de ressources rares se résolvent par des algorithmes de coloration : sommets = objets à placer, arêtes = incompatibilités, couleurs = ressources (créneau, zone, fréquence, registre).

III. Trouver une coloration propre

Exemple fil rouge : 8 produits chimiques dangereux à répartir en zones de stockage, p1 incompatible avec p4, p2 avec p3, p3 avec p2, p4, p5, p8, etc. (graphe ci-dessous, détail dans l'exercice 4 corrigé).

1. L'algorithme séquentiel

PrincipeParcourir les sommets les uns après les autres et attribuer à chaque sommet la plus petite couleur non déjà utilisée par un de ses voisins.
Pour chaque sommet i :
    c ← 0
    Faire :
        test ← vrai
        Pour chaque sommet j < i :
            si j est adjacent à i et que la couleur de j est c : test ← faux
        si (test = faux) c ← c + 1
    Tant que (test = faux)
    Attribuer la couleur c à i

Version Java (testée), où ordre donne l'ordre de traitement :

static int[] sequentiel(boolean[][] adj, int[] ordre) {
    int n = adj.length;
    int[] couleur = new int[n];
    Arrays.fill(couleur, -1);
    for (int i : ordre) {
        int c = 0;
        boolean test;
        do {
            test = true;
            for (int j = 0; j < n; j++) {
                if (adj[i][j] && couleur[j] == c) test = false;
            }
            if (!test) c++;
        } while (!test);
        couleur[i] = c;
    }
    return couleur;
}

Cet algorithme donne toujours une coloration propre. Mais le nombre de couleurs dépend de l'ordre de traitement : sur les produits chimiques, l'ordre p1…p8 utilise 3 zones, un autre ordre n'en utilise que 2 (exercice 4).

2. Comment choisir l'ordre de traitement ?

Stratégies
  • Degré décroissant (Welsh-Powell) : on traite d'abord les sommets qui ont le plus de voisins, c'est-à-dire les plus contraints (ceux qui ont le plus de chances de poser problème plus tard).
  • DSATUR : à chaque étape, on choisit le sommet non coloré dont les voisins portent le plus de couleurs différentes (« degré de saturation »), en cas d'égalité celui de plus grand degré. L'ordre n'est plus fixé à l'avance : il s'adapte à la coloration en cours.

3. Obtenir une solution optimale ?

Même avec l'ordre « degré décroissant », rien ne garantit l'optimalité : sur le graphe de l'exercice 5 (12 sommets), l'algorithme amélioré utilise 3 couleurs alors que χ = 2. Trouver χ(G) est un problème difficile (NP-difficile dans le cas général) : les algorithmes gloutons sont des heuristiques qui donnent une borne supérieure.

Compléments utiles pour encadrer χ(G)
  • Borne inférieure : si G contient une clique (sous-graphe complet) Kk, alors χ(G) ≥ k. Dès qu'une arête existe, χ ≥ 2 ; avec un triangle, χ ≥ 3.
  • Borne supérieure : l'algorithme séquentiel n'utilise jamais plus de Δ+1 couleurs, où Δ est le degré maximum.
  • Graphes bipartis : χ(G) ≤ 2 ⇔ G n'a pas de cycle de longueur impaire. Les graphes des exercices 4 et 5 sont bipartis : leur nombre chromatique est 2.
  • χ(Kn) = n.
BilanModéliser (sommets = objets, arêtes = incompatibilités, couleurs = ressources) → colorier avec un bon ordre → encadrer χ(G) : borne inférieure par une clique, borne supérieure par l'algorithme glouton.
