Chapitre 2 — Modéliser et représenter

  1. Identifier les données (entités, relations, informations sur les relations).
  2. Construire le graphe (sommets ? arêtes ou arcs ? exemples dessinés).
  3. Diagramme de classes UML (classes, attributs, relations, cardinalités).

Démarche itérative et incrémentale : modèle → mise à l'épreuve → limites → modèle enrichi. Exemples : information sur le couple (U1,U2) → portée par le lien ; Raspail–Denfert → multigraphe. Modèle conceptuel ≠ modèle d'implémentation (traitements, stockage, performance).

Chapitre 3 — Coloration

NotionÀ retenir
Degrédeg(s) = nombre d'arêtes incidentes ; deg(s) ≤ n−1 ; Σ deg = 2m
Pendant / isoléun seul voisin (degré 1) / aucun voisin (degré 0)
Sous-grapheon garde certains sommets et les arêtes entre eux
Graphe partielon garde tous les sommets, certaines arêtes
Kncomplet : degrés n−1, n(n−1)/2 arêtes ; χ(Kn) = n
Coloration propresommets adjacents ⇒ couleurs différentes
k-colorablecoloration propre avec k couleurs
Nombre chromatique χ(G)plus petit k tel que G soit k-colorable
Production / décisiontrouver une coloration, trouver χ(G) / G est-il k-colorable ? existe-t-il une coloration minimale ?
Algorithme séquentielPour chaque sommet (dans un certain ordre) : lui donner la plus petite couleur non utilisée par ses voisins déjà colorés. Toujours propre, pas forcément optimal, dépend de l'ordre.
  • Welsh-Powell : ordre de degré décroissant. DSATUR : on choisit le sommet de plus grande saturation (couleurs différentes chez ses voisins), puis le plus grand degré.
  • Même « amélioré », le glouton n'est qu'une heuristique (exercice 5 : 3 couleurs alors que χ = 2). Trouver χ(G) est NP-difficile.
  • Borne inférieure : une clique Kk ⇒ χ ≥ k. Borne supérieure : le glouton donne au plus Δ+1 couleurs. χ ≤ 2 ⇔ aucun cycle impair (biparti).

Modéliser un problème par une coloration

Sommets = objets à placer · arêtes = incompatibilités / conflits · couleurs = ressources (créneau, zone, fréquence, registre).

ProblèmeRésultat
Produits chimiques (ex. 4)ordre p1…p8 : 3 zones ; ordre de degré décroissant : 2 zones ; χ = 2
Graphe de l'exercice 5glouton : 3 couleurs ; optimum : 2 (biparti)
Examens (activité 4)clique {Cn, E, M, S} ⇒ χ ≥ 4 ; 4 créneaux suffisent ; sans Physique ni SVT : 3 créneaux
Pièges classiques
  • Confondre sous-graphe et graphe partiel ; confondre ordre (sommets) et taille (arêtes).
  • Dans un multigraphe, successeurs ≠ arcs sortants.
  • Croire que le glouton donne χ(G) : il donne une coloration propre, dépendante de l'ordre.
  • Oublier que deux sommets non adjacents peuvent partager une couleur (et c'est le but !).
  • Matrice d'adjacence : ligne = successeurs, colonne = prédécesseurs.
